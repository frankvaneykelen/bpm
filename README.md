# bpm
App to measure the beats per minute of a song by tapping. With decimal values, the min, max and avg values, and a gauge indicating the stability of the measurement. 

## Usage
Open `index.html` in a browser. Tap the button (or press space) in time with the song. Shows BPM with one decimal, min/avg/max, and a stability gauge (based on the variation of the tap intervals). Reset clears the measurement.
