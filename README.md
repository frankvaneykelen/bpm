# bpm
App to measure the beats per minute of a song by tapping. With decimal values, the min, max and avg values, and a gauge indicating the stability of the measurement. 

## Usage
Open `index.html` in a browser. Tap the button (or press space) in time with the song. Shows BPM with one decimal, avg, and a stability gauge (based on the variation of the tap intervals). Min and max appear after the measurement first reaches 80% stability. Reset clears the measurement.
